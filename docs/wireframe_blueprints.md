# Wireframe Blueprints — Tamil Streetwear Shopify Theme

## 1. Homepage Wireframe

**Layout Structure**
- **Header / Nav Bar**  
  - Logo (top-left, Tamil Unicode support).  
  - Nav links: Home, Shop, Culture, Lookbook, FAQ, Contact.  
  - Language toggle (EN ↔ தமிழ்).  
  - Currency switcher.  
  - Cart icon.

- **Hero Section**  
  - Full-width background image or video.  
  - Overlay headline with Tamil-inspired typography.  
  - CTA button: “Shop the Drop.”

- **Drop Countdown Section**  
  - Large numeric countdown timer.  
  - Supporting text: “Next Drop In…”

- **Tamil Proverb Rotator**  
  - Rotating proverb in Tamil script.  
  - English translation beneath.

- **Featured Collections Grid**  
  - 2–3 large tiles with product category images.  
  - Cultural-inspired borders/patterns.

- **Newsletter Signup**  
  - Minimalist input field + button.  
  - Subtext: “Be the first to know about new drops.”

- **UGC / Community Showcase**  
  - Instagram/TikTok feed integration.  
  - Grid layout with 4–6 customer images.

- **Footer**  
  - Quick links, email signup, social links.

## 2. Collection Page (PLP) Wireframe

**Layout Structure**
- **Header** (same as homepage).

- **Filter/Sort Bar**  
  - Dropdowns: Size, Price, Type.  
  - Sort options: Newest, Price Low→High, Price High→Low.

- **Product Grid**  
  - 3–4 columns desktop / 2 columns mobile.  
  - Product card includes:  
    - Product image.  
    - Hover state → alt image.  
    - Product title.  
    - Price (with currency switch).  
    - Badge (New, Limited, Bestseller).

- **Quick Add**  
  - Hover overlay “+ Add to Cart.”

- **Pagination / Infinite Scroll**  
  - Infinite scroll preferred, fallback “Load More.”

---

## 3. Product Page (PDP) Wireframe

**Layout Structure**
- **Gallery Section**  
  - Main image with thumbnails below (desktop).  
  - Swipeable gallery (mobile).

- **Product Details Column**  
  - Product title (Tamil + English if applicable).  
  - Price.  
  - Variant selectors (Color swatches, Size dropdown).  
  - Stock status.  
  - Sticky add-to-cart (mobile).  

- **Design Story Panel**  
  - Section header in Tamil script.  
  - English translation below.  
  - Short cultural backstory text.  
  - Optional artist credit.

- **Care & Materials**  
  - Tabbed or accordion section.  
  - Fabric, care instructions, print method.

- **Shipping & Returns**  
  - Delivery estimate by market.  
  - POD production note.

- **Size Guide Modal**  
  - Triggered by button.  
  - Pop-up modal with measurement chart.  
  - Cultural border styling.

- **Related Items Carousel**  
  - Horizontally scrollable.  
  - 3–4 products shown.

- **Reviews Section**  
  - Loox/Judge.me integration.  
  - Star rating, user photos, comments.

---

## 4. Global Styling & Cultural UI Notes
- Use **Kolam / rangoli pattern borders** for key callouts.  
- **Tamil script-inspired typography** for headers, balanced with modern sans-serif.  
- **Temple silhouette motifs** as subtle dividers.  
- Cultural yet minimalist color palette: Deep maroon, gold accents, muted cream, charcoal black.  
- Accent graphics inspired by Tamil cinema posters and folklore.

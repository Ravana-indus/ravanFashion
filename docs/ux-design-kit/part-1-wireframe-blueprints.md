# Part 1: Wireframe Blueprints

## 1. Homepage

- **Header / Nav Bar**: Logo (Tamil Unicode), nav links, EN ↔ தமிழ் toggle, currency switcher,
  cart.
- **Hero Section**: Full-width image/video, Tamil-inspired headline, CTA.
- **Drop Countdown**: Numeric timer, supporting text.
- **Tamil Proverb Rotator**: Tamil script + English translation.
- **Featured Collections Grid**: Tiles with cultural motif borders.
- **Newsletter Signup**: Input + CTA.
- **UGC Showcase**: Social feed grid.
- **Footer**: Quick links, email signup, socials.

## 2. Collection Page (PLP)

- **Filter/Sort Bar**: Size, price, type, sorting options.
- **Product Grid**: Hover alt image, product title, price, badges.
- **Quick Add to Cart** overlay.
- **Infinite Scroll / Load More**.

## 3. Product Page (PDP)

- **Gallery**: Main image + thumbnails (desktop), swipeable (mobile).
- **Details Column**: Title, price, variants, stock, sticky ATC.
- **Design Story Panel**: Tamil script heading, English translation, cultural backstory.
- **Care & Materials** (accordion).
- **Shipping & Returns** info.
- **Size Guide Modal** with Tamil pattern border.
- **Related Items Carousel**.
- **Reviews Section**.

## 4. Global Styling Notes

- Kolam borders, temple silhouettes, Tamil script typography, minimal color palette.

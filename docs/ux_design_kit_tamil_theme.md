# UX Design Kit — Tamil Cultural Streetwear Shopify Theme

This kit consolidates the **Wireframe Blueprints** and **Style Guide** for the Tamil cultural streetwear brand’s Shopify theme.

---

## Part 1: Wireframe Blueprints

### 1. Homepage
- **Header / Nav Bar**: Logo (Tamil Unicode), nav links, EN ↔ தமிழ் toggle, currency switcher, cart.  
- **Hero Section**: Full-width image/video, Tamil-inspired headline, CTA.  
- **Drop Countdown**: Numeric timer, supporting text.  
- **Tamil Proverb Rotator**: Tamil script + English translation.  
- **Featured Collections Grid**: Tiles with cultural motif borders.  
- **Newsletter Signup**: Input + CTA.  
- **UGC Showcase**: Social feed grid.  
- **Footer**: Quick links, email signup, socials.

### 2. Collection Page (PLP)
- **Filter/Sort Bar**: Size, price, type, sorting options.  
- **Product Grid**: Hover alt image, product title, price, badges.  
- **Quick Add to Cart** overlay.  
- **Infinite Scroll / Load More**.

### 3. Product Page (PDP)
- **Gallery**: Main image + thumbnails (desktop), swipeable (mobile).  
- **Details Column**: Title, price, variants, stock, sticky ATC.  
- **Design Story Panel**: Tamil script heading, English translation, cultural backstory.  
- **Care & Materials** (accordion).  
- **Shipping & Returns** info.  
- **Size Guide Modal** with Tamil pattern border.  
- **Related Items Carousel**.  
- **Reviews Section**.

### 4. Global Styling Notes
- Kolam borders, temple silhouettes, Tamil script typography, minimal color palette.

---

## Part 2: Style Guide

### 1. Color Palette
- Deep Maroon (#6A1B1B), Gold (#D4AF37), Charcoal Black (#1C1C1C), Cream White (#FDF6EC), Muted Teal (#3A6A6A).

### 2. Typography
- **Tamil Unicode** (Latha/Adyuthan Tamil) for headers, proverbs, cultural sections.  
- **Sans-serif modern** (Inter/Helvetica Neue) for English body and UI text.

### 3. Iconography
- Inspired by Kolam, temple gopuram silhouettes, lotus, conch.  
- Minimal/monoline SVGs for modern aesthetic.

### 4. UI Elements
- **Buttons**: Gold primary CTA, maroon outline secondary.  
- **Badges**: Kolam star for “New”, Gold outline for “Limited”, Maroon for “Bestseller”.  
- **Borders/Dividers**: Kolam-inspired geometric lines.

### 5. Imagery
- Diaspora models in urban + cultural backdrops.  
- Editorial, bold contrast photography.  
- Authentic lifestyle shoots prioritized.

### 6. Accessibility
- EN translations for all Tamil text.  
- WCAG AA contrast compliance.  
- Responsive font scaling.  
- Inclusive imagery.

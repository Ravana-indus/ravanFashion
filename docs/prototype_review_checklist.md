# Prototype Review Checklist — UX Expert (Anita)

This checklist is for validating **high-fidelity prototypes** before handoff back to PM Sarah. It is also structured as **Kanban subtasks** under the “UX Refinement” column for tracking.

---

## 1. Layout & Structure
- [ ] Homepage includes all planned sections (Hero, Drop Countdown, Proverb Rotator, Featured Collections, Newsletter, UGC). (**Critical**)  
- [ ] PLP grid displays correctly with filter/sort bar, product cards, badges, quick-add, infinite scroll. (**High**)  
- [ ] PDP includes gallery, details, variant selectors, Design Story, care notes, size guide, related items, reviews. (**Critical**)

## 2. Cultural Visual System
- [ ] Tamil Unicode typography applied to headers and cultural touchpoints. (**Critical**)  
- [ ] English translations paired with all Tamil text. (**Critical**)  
- [ ] Kolam/rangoli borders used for dividers or accents. (**Medium**)  
- [ ] Temple/folklore motifs integrated subtly without clutter. (**Medium**)  
- [ ] Color palette (maroon, gold, charcoal, cream, teal) applied consistently. (**High**)

## 3. Mobile-First UX
- [ ] Mobile wireframes tested for TikTok/IG-driven traffic. (**Critical**)  
- [ ] Sticky add-to-cart visible and functional on mobile. (**High**)  
- [ ] Navigation simplified for small screens. (**High**)  
- [ ] Swipeable galleries validated. (**Medium**)

## 4. Accessibility
- [ ] Color contrast ratios meet WCAG AA. (**Critical**)  
- [ ] All text legible in Tamil and English. (**Critical**)  
- [ ] Fonts scale responsively across devices. (**High**)  
- [ ] Keyboard navigation flows confirmed. (**Medium**)  
- [ ] Alt text placeholders included for all imagery. (**High**)

## 5. Storytelling Touchpoints
- [ ] Tamil proverb rotator styled with dual-script text. (**High**)  
- [ ] Design Story panels culturally authentic and visually distinct. (**Critical**)  
- [ ] Drop storytelling sections styled to highlight exclusivity. (**Medium**)  
- [ ] UGC/community showcase styled with cultural frames. (**Medium**)

## 6. Prototype Presentation
- [ ] Figma/Sketch/Adobe XD file organized with proper naming. (**High**)  
- [ ] Components and styles centralized for consistency. (**High**)  
- [ ] All pages linked in prototype flow (homepage → PLP → PDP → checkout). (**Critical**)  
- [ ] Annotations added for dev team (hover states, responsive rules, interactions). (**High**)

---

✅ Once Anita completes this checklist, prototypes are ready for **PM Sarah’s validation** and subsequent **Stage 6: Dev Implementation**. 

📌 **Kanban Mapping:**  Each checkbox item is a **subtask card** under the **UX Refinement column** in the tracker, now labeled with **priority tags (Critical / High / Medium)**.

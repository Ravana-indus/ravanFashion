# Tamil Theme UI Style Guide

A comprehensive style guide for the Tamil-inspired Shopify fashion theme.

## 1. Color Palette

- **Deep Maroon**: #6A1B1B (Primary brand color)
- **Gold**: #D4AF37 (Accent and CTA color)
- **Charcoal Black**: #1C1C1C (Text and contrast)
- **Cream White**: #FDF6EC (Background and light elements)
- **Muted Teal**: #3A6A6A (Secondary accent)

## 2. Typography

- **Tamil Unicode**: Latha/Adyuthan Tamil for headers, proverbs, cultural sections
- **Sans-serif Modern**: Inter/Helvetica Neue for English body and UI text
- Responsive font scaling for accessibility
- Clear hierarchy between Tamil and English content

## 3. Iconography

- Inspired by traditional Tamil cultural elements:
  - Kolam geometric patterns
  - Temple gopuram silhouettes
  - Lotus motifs
  - Conch shell designs
- Minimal/monoline SVG style for modern aesthetic
- Scalable vector graphics for all screen sizes

## 4. UI Elements

### Buttons

- **Primary CTA**: Gold background (#D4AF37) with dark text
- **Secondary**: Maroon outline (#6A1B1B) with transparent background
- **Tertiary**: Text-only links in brand colors

### Badges & Labels

- **"New" Products**: Kolam star icon with gold accent
- **"Limited Edition"**: Gold outline badge
- **"Bestseller"**: Maroon background badge
- **Cultural Items**: Tamil script labels where appropriate

### Borders & Dividers

- Kolam-inspired geometric line patterns
- Subtle cultural motifs as section separators
- Clean, minimal borders for modern look

## 5. Imagery Guidelines

- **Models**: Diaspora representation in urban + cultural settings
- **Photography Style**: Editorial with bold contrast
- **Lifestyle Shots**: Authentic, non-stereotypical portrayals
- **Product Photos**: Clean, consistent lighting and backgrounds
- **Cultural Elements**: Respectful integration of Tamil heritage

## 6. Accessibility Standards

- **Language Support**: English translations for all Tamil text
- **Color Contrast**: WCAG AA compliance for all text/background combinations
- **Font Scaling**: Responsive typography that scales properly
- **Alt Text**: Descriptive alternative text for cultural imagery
- **Inclusive Design**: Representation across diverse backgrounds

## 7. Layout Principles

- **Mobile-First**: Responsive design prioritizing mobile experience
- **Cultural Balance**: Thoughtful integration of Tamil elements without overwhelming
- **White Space**: Clean, modern spacing around cultural elements
- **Grid System**: Consistent alignment and proportions
- **Navigation**: Intuitive bilingual navigation structure

## 8. Animation & Interactions

- **Micro-interactions**: Subtle hover states with cultural flair
- **Loading States**: Kolam-inspired loading animations
- **Transitions**: Smooth, purposeful animations
- **Cultural Elements**: Gentle animations for proverb rotations

---

This style guide ensures consistent, respectful, and accessible implementation of Tamil cultural
elements within a modern e-commerce experience.

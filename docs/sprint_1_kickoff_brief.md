## Day-by-Day Standup Agenda

### Day 1: Kickoff & Setup
- Repo initialized, Shopify CLI linked.
- Tailwind/PostCSS config.
- UX delivers Tamil typography kit.
- QA drafts smoke tests.

### Day 2: Foundation Progress
- CI/CD pipeline verification.
- Header/footer scaffolding.
- UX: Logo + brand palette delivery.
- QA: Verify environment readiness.

### Day 3: Branding Integration
- Header/footer styled with Tamil fonts.
- Locale toggle implemented (EN ↔ தமிழ்).
- QA tests locale switch.
- PM checks burndown tracking start.

### Day 4: Homepage Hero
- Hero banner with Tamil/English text.
- CTA buttons linked.
- QA validates accessibility.
- Marketing: Prepare first Klaviyo template.

### Day 5: Countdown & Proverbs
- Drop countdown implemented.
- Tamil proverb rotator added.
- QA: Timer accuracy + screen reader check.
- UX validates typography & motion design.

### Day 6: Featured Collections
- Featured collection grid live.
- Hover states styled.
- QA verifies products loading from Shopify.
- PM mid-sprint checkpoint prep.

### Day 7: Newsletter & Mid-Sprint Review
- Newsletter signup integrated with Klaviyo.
- UGC block (Instagram/TikTok) tested.
- Mid-sprint review meeting with demo.
- PM adjusts backlog if needed.

### Day 8: Collection Page Skeleton
- Collection page grid built.
- Filter/sort scaffolding.
- QA checks grid responsiveness.
- UX provides cultural motifs for styling.

### Day 9: Product Page Variants
- Variant selectors implemented.
- Design story block added.
- QA validates data binding.
- PM confirms acceptance coverage.

### Day 10: Size Guide & Reviews
- Size guide modal implemented.
- Reviews app integrated (Loox/Judge.me).
- QA validates modal accessibility.

### Day 11: Performance Optimization

- PM updates burndown vs. velocity.

### Day 12: QA Deep Dive
- Full regression on homepage, PLP, PDP.
- Cross-browser/device testing.
- Bug triage session.
- UX validates final Tamil UI polish.

### Day 13: Final Fixes & Pre-Launch Checklist
- Address QA bugs.
- Validate POD sync (Printful/Printify).
- PM reviews pre-launch checklist.
- Marketing: Schedule first campaign.

### Day 14: Sprint Review & Retrospective
- Final demo of theme on dev store.
- QA signs off acceptance criteria.
- Retrospective meeting (what went well, improvements).
- PM logs velocity for forecasting Sprint 2.
